# P2 Handoff — Post-period forest probability channels

**For:** Deforestation-model team (downstream consumers of the forest mask).
**From:** Lino (forest-detection workstream).
**Status:** Ready to integrate. Channels cached per tile in [`cache_probs/`](../../cache_probs/).

---

## TL;DR — one sentence

Three new per-tile float32 rasters — `forest_prob_pre`, `forest_prob_post`, `forest_prob_delta` — are cached in `cache_probs/<tile_id>.npz` and can be concatenated as three extra feature channels to your deforestation training/inference tensors.

---

## What these channels mean

| channel | shape | dtype | range | meaning |
|---------|-------|-------|-------|---------|
| `forest_prob_pre`   | `(H, W)` | `float32` | `[0, 1]` | P(forest) from the **pre-period** masker (same model as `LearnedForestMasker.predict_proba` — P1-shipped config, tree dims A18/21/26/28/34 included). |
| `forest_prob_post`  | `(H, W)` | `float32` | `[0, 1]` | P(forest) from an analogous masker trained on **post-period** features (`s2_post_*`, `s1_post_*`, `aef_post`). Positives = "truly still forest" = `forest_gt_pre2020 == 1 AND label == 0`. |
| `forest_prob_delta` | `(H, W)` | `float32` | `[-1, 1]` | `forest_prob_pre - forest_prob_post`. **Positive delta ≈ lost forest-like appearance between pre and post period** — the primary deforestation signal of this artifact. |

All three rasters share the tile's canonical `(H, W)` — no resampling needed.

---

## How to load + integrate

### 1) Load a tile's probability channels

```python
import numpy as np
from pathlib import Path

tile_id = "48PWV_7_8"
probs = np.load(Path("cache_probs") / f"{tile_id}.npz")
prob_pre   = probs["forest_prob_pre"]     # (H, W) float32 in [0,1]
prob_post  = probs["forest_prob_post"]    # (H, W) float32 in [0,1]
prob_delta = probs["forest_prob_delta"]   # (H, W) float32 in [-1,1]
```

### 2) Add to your existing feature stack (training + inference, same way)

If your deforestation model consumes a `(C, H, W)` feature tensor assembled from the main cache, simply stack these three channels on:

```python
extra = np.stack([prob_pre, prob_post, prob_delta], axis=0)   # (3, H, W)
features = np.concatenate([features, extra], axis=0)          # (C+3, H, W)
```

Do this **identically at train and inference time.** No normalization is required (values are already bounded).

### 3) (Optional) Use `prob_pre` as a hard prefilter

If you want a cheap precision guardrail, you can mask out predictions on pixels with `prob_pre < 0.3` (these are pixels our model is confident were **never forest** pre-2020, so they can't be deforested). This is equivalent to `LearnedForestMasker.predict_tiers(...) >= UNCERTAIN`.

```python
was_forest = prob_pre >= 0.3        # NON_FOREST threshold from LearnedForestMasker
predictions[~was_forest] = 0        # can't deforest something that wasn't forest
```

The existing `LearnedForestMasker` API (`predict_proba`, `predict_tiers`, tier thresholds) is **unchanged** — P1/P2 do not break your current wiring.

## Signal strength — be honest about expectations

On **pre-forest pixels** (`prob_pre >= 0.5`) in training tiles:

| class | mean `prob_delta` |
|-------|-------------------|
| deforested (`label == 1`)     | **+0.151** |
| non-deforested (`label == 0`) | +0.058 |

- **Separation:** 0.43σ — weak but real. Deforested pixels lose forest-probability ~3× more than stable ones.
- **`delta > 0.3` as a hard classifier:** precision 0.25, recall 0.20. **Don't use delta alone as a classifier.**
- **Recommended use:** feed all three channels as continuous features into your existing deforestation model. The gradient booster will weight them against the other signals it already has. Expect a modest, not dramatic, lift.
- **Where the noise comes from:** seasonal NDVI variation, clouds, AEF annual-embedding drift unrelated to disturbance. The masker can't fully disentangle these without supervised post-period labels.

## Regeneration / reproducibility

The cache was generated by:

```bash
python code/reports/p2_post_period.py --cache_dir ./cache
```

- Deterministic with `--seed 0` (default).
- Takes ~3–4 min on all 16 tiles.
- Writes to `cache_probs/<tile_id>.npz` — does **not** mutate the shared `cache/`.
- If you regenerate, overwrite in-place is fine; the masker API / features are frozen.

## Open questions (flag if you hit these)

- **Pre-period coverage is ~0.77** (see `P0_BASELINE_AUDIT.txt`). Pixels below the UNCERTAIN threshold have `prob_pre < 0.3` → the delta channel is mostly meaningless there. Your model can either ignore them (hard prefilter) or rely on the original features. If you see the model putting weight on delta in non-forest regions, treat that as noise.
- **No MGRS-aware validation was performed for P2** (only 10 training tiles, small sample). If you do per-tile cross-validation and see delta helping in some zones but not others, flag it — happy to retrain.
- **Test tiles (6 of 16)** have no `forest_gt_pre2020`, so the post-period masker was trained only on the 10 labeled tiles. Predictions on all 16 are still valid (just no GT to validate them against).
